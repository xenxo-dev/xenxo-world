# {{title}} — distrito de xenxo

Un distrito de la comunidad de [xenxo.io](https://xenxo.io): 256 × 256 m del mundo, descritos en
`xenxo-district.json` y con los modelos de esta carpeta.

```bash
npm install
npm run validate        # comprueba el distrito como lo hará xenxo
```

Después, súbelo desde **xenxo.io → Cuenta → Tu distrito**: queda en borrador (solo lo ves tú),
lo pruebas y lo envías a revisión. Todas las reglas y medidas: **AGENTS.md** (también para tu IA).

---

A community district for [xenxo.io](https://xenxo.io): 256 × 256 m of the world, described in
`xenxo-district.json` with the models in this folder. `npm run validate` checks it the way xenxo
will; then upload it from **xenxo.io → Account → Your district**. Rules and sizes: **AGENTS.md**.
